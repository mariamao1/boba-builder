Prepare your sheet

One row per drink. Only Name and Drink are required; blank options use the shop’s defaults.

ColumnRequiredExampleNotes
NameyesAlice Who the drink is for.
DrinkyesTaro Slush Close enough is fine — we match it to the menu.
SizenoLarge Medium, Large, or Hot. Hot is a size here, not a separate drink.
Sugarno50% A percentage reads best: 0%, 30%, 50%, 70%, 100%.

ToppingsnoBoba, Pudding Separate several with commas.

Download the template
Use it as a Google Sheet
  1. Download the template above.
  2. In Google Sheets: File → Import → Upload, pick the file, choose Replace spreadsheet.
  3. Share it with your group and let everyone add a row.
  4. Then either paste the link below, or File → Download → CSV and upload it.

Pasting a link needs the sheet set to Anyone with the link (Viewer is enough) — otherwise Google won't let us read it. Uploading a file never needs sharing.
